# Dotfiles

- DESC: Dotfiles for misc systems and environments
- REPO: https://github.org/mandober/dotfiles
- MAKE: 2018-02-01
- EDIT: 2024-08-18


Configuration settings for the following shartefacts:
- bash history
- bash globbing
- bash shopt
- bash vars
- bash completions
- bash aliases
- bash functions, hooks and handles
- bash prompt
- terminal
- locale
- ulimit
- PATH
- environment vars
- ls, dircolor
- xcompose files
