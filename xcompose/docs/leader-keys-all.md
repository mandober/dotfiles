# XCompose :: Index of leader keys

Index of possible leader keys

- ↑ Up
- ↓ Down
- ← Left
- → Right
- 1,              exclam        (!)
- 2,              at            (@)
- 3,              numbersign    (#)
- 4,              dollar        ($)
- 5,              percent       (%)
- 6,              asciicircum   (^)
- 7,              ampersand     (&)
- 8,              asterisk      (*)
- 9,              bracketleft   ([)
- 0,              bracketright  (])
- grave      (`), asciitilde    (~)
- underscore (_), minus         (-)
- equal      (=), plus          (+)
- parenleft  ((), braceleft     ({)
- parenright ()), braceright    (})
- slash      (/), bar           (|)
- colon      (:), semicolon     (;)
- apostrophe ('), quotedbl      (")
- comma      (,), less          (<)
- period     (.), greater       (>)
- backslash  (\), (not used)    (?)
- space      ( )
